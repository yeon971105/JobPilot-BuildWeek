# Judging criteria mapping

| Criterion | Evidence |
| --- | --- |
| Technological Implementation | Deterministic 100-point score reconciliation; versioned provider modes; Responses API Structured Outputs; grounding validation of requirement/evidence IDs; timeout, quota, health endpoint, tests. |
| Design | No-login focused workflow; synthetic candidate disclosure; readable evidence cards; score buckets; technical-details disclosure; tracker; responsive route structure. |
| Potential Impact | Helps job seekers choose where to spend scarce application time with explanation instead of opaque ranking. Claims are limited to decision support, not hiring prediction. |
| Quality of the Idea | Separates generative strategy from deterministic scoring, local privacy mode from public synthetic demo mode, and Build Week extension from earlier JobPilot foundation. |
