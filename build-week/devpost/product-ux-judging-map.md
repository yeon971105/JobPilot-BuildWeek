# Product UX Judging Map

> **HISTORICAL_SUPERSEDED:** Retained pre-RC4 mapping. The current map is `build-week/devpost/owner-review-judging-map.md`.

| Judge question | Product evidence |
| --- | --- |
| Is the problem clear? | Landing: “Know why a job fits.” and an immediate no-login demo. |
| Is AI use meaningful? | Gemma performs semantic requirement/evidence work; deterministic code owns score math; optional GPT-5.6 handles bounded heavy reasoning. |
| Is the decision understandable? | Role Overview shows score, priority, match, gap, experience, constraint, and primary action in the first desktop viewport. |
| Is the score transparent? | Evidence and Experience tabs plus Score Proof, downloadable receipt, hash, zero hidden adjustments, and See a Score Change. |
| Is privacy credible? | Public mode rejects uploads; local mode parses PDF/DOCX/TXT in memory and restricts model traffic to loopback Ollama. |
| Is it usable? | Profile control, filters, four detail tabs, focused modals, browser-local tracker, and responsive 1440/1024/390/320 certification. |
| Is the demo reliable? | Six synthetic roles and prepared analyses require no account, database, Ollama, or API key. |
| What did Codex contribute? | Defect discovery, scorer/UX repair, private-mode implementation, tests, audits, media, documentation, and release packaging. |

Submission and final deployment remain prohibited until the user approves this RC.
